Balancing chemical equations

Atoms are neither created nor destroyed in a reaction, so both sides of an equation must contain the same atoms.

Antoine Lavoisier's experiments in the late 1700s established that the total mass is unchanged in a chemical reaction. In an equation this means each element appears the same number of times on both sides. Hydrogen burning in oxygen is balanced as 2 H₂ + O₂ → 2 H₂O: four hydrogen atoms and two oxygen atoms on each side.

Balancing means choosing the smallest whole-number coefficients that achieve this. The balancer on this site does it by treating each element as a linear equation and solving the system exactly.
