About

How this works, and how far to trust it

A small reference built to be read, with its confidence shown. It is not a substitute for a textbook or a standards body.

The marks on numbers

  • ExactExact by definition. The number is part of how the unit or constant is defined, so it has no uncertainty.
  • MeasuredFound by experiment. The figure in brackets is the uncertainty in the last digits, and later measurements may refine it.
  • RoundedRounded for readability, or a typical value that varies. Do not use it where precision matters; use the measured figure.

Each mark is a rule style plus a word, never colour alone. Solid means exact, dashed measured, dotted rounded.

Where the facts come from

  • Every fact lives in a data file (data/elements.json, topics.json, constants.json) and the pages are generated from them, so a count printed in a sentence always matches the table or drawing beside it.
  • The text and values were written from general knowledge and have not yet been checked line by line against IUPAC, CODATA, NIST or textbooks. The exact SI constants and the element names and numbers are the most reliable parts; the topic prose is a short summary.
  • The periodic table uses one common layout and one common set of categories. Sources differ on, for example, where to put lanthanum and lutetium and which elements count as metalloids; the table page says which convention it follows.
  • The equation balancer is checked against known answers, including awkward ones such as the permanganate and hexacyanoferrate reactions.

Report a mistake

The most useful report names the page, quotes the sentence or value, and cites a source (a standards body, a textbook edition and page, or a paper).
